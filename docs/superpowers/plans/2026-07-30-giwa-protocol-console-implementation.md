> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the approved Mission Cockpit → Live Execution Rail → Receipt Artifact experience in the existing `/user` participant flow without changing wallet, API, verifier, contract, or persistence behavior.

**Architecture:** Keep `apps/web/public/user-flow.js` as the dependency-light runtime and add a pure presentation projection that maps the existing detailed run state into one of three public views. Reuse the current wallet and transaction actions, while replacing only the `/user` and matched Receipt render trees and their scoped CSS. The `/giwa-demo` evaluator route remains behaviorally independent.

**Tech Stack:** Browser JavaScript, semantic HTML generated by the existing `view()` helper, CSS, Pretendard Variable, Vitest source-contract tests, the existing static/live Node servers.

## Global Constraints

- Public product name remains `GIWA Verified Intent Rail`.
- GIWA Sepolia testnet and mock assets only.
- Do not claim real funds, yield, RWA issuance, settlement, KYC, security approval, mainnet readiness, or finality.
- Keep existing wallet, Manifest, transaction, verifier, Receipt, API, and storage behavior unchanged.
- Expose only `조건 확인 → 지갑 실행 → 결과 공개` as the participant journey.
- Keep detailed states inside the execution workspace: `실행 준비 → 지갑 승인 → 트랜잭션 제출 → 조건 대조 → Receipt 발급`.
- Use the existing `/matched-receipt-seal.png`; do not create a replacement asset.
- Preserve keyboard focus, live-region announcements, reduced motion, and 320px horizontal-overflow protection.
- Do not stage, commit, push, deploy, or change cloud infrastructure.

```js
function projectProtocolConsoleState(input) {
  const activeView = input.receiptReady
    ? "receipt"
    : input.depositSubmitted || input.verifying || input.mismatched
      ? "execution"
      : "mission";
  const publicOrder = ["mission", "execution", "receipt"];
  const publicIndex = publicOrder.indexOf(activeView);
  return {
    activeView,
    publicStages: publicOrder.map((id, index) => ({
      id,
      state:
        id === "execution" && input.mismatched
          ? "blocked"
          : index < publicIndex
            ? "complete"
            : index === publicIndex
              ? "active"
              : "pending"
    })),
    executionStages: [
      { id: "prepare", state: "complete" },
      { id: "wallet", state: input.approvalSubmitted ? "complete" : "active" },
      { id: "submit", state: input.depositSubmitted ? "complete" : "pending" },
      {
        id: "match",
        state: input.mismatched
          ? "blocked"
          : input.verifying
            ? "active"
            : input.receiptReady
              ? "complete"
              : "pending"
      },
      { id: "receipt", state: input.receiptReady ? "complete" : "pending" }
    ]
  };
}
```
