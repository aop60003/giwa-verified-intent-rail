# GIWA Provenance Artifact Manifest

## Purpose

This document defines Sprint 21 artifact manifest and provenance report shape. It is a documentation-only contract. It does not create release artifacts, does not create fake hashes, and does not unblock staging.

## Authority Boundary

Artifact manifest and provenance report outputs are release-grade only when generated by protected CI from immutable source.

Local dry-runs are diagnostic and must be labeled:

```text
authority=local-advisory
```

## Hash Policy

File hashes:

```text
algorithm=sha256
input=raw-file-bytes
pathStyle=repo-relative-posix
aggregateLineEnding=lf
aggregateSort=normalized-path-ascending
```

Build tree hash input:

```text
<sha256><two spaces><repo-relative-posix-path><lf>
```

The build tree hash is the SHA-256 of all sorted build tree input lines.

Domain hashes from protocol evidence remain separate from file hashes:

```text
intentHash
verifierInputHash
receiptHash
```

Those values are recomputed from sanitized public evidence when available and recorded under `domainHashes`, not mixed with file SHA-256 fields.

## Public Artifact Policy

The artifact manifest must cover every served file under `apps/web/public`. If the writer finds an unmanifested public file, it fails closed.

The provenance report binds to the exact artifact manifest through `artifactManifestSha256` and copied `buildTreeSha256`.

The provenance report itself should be hashed through a `.sha256` sidecar. A report cannot safely include its own file hash inside the same JSON without a circular hash problem.

## Sprint 22 Local Advisory Implementation

Sprint 22 implements local diagnostic inventory, file hashing, public artifact scanning, and manifest-bound provenance reporting.

Local output paths:

```text
docs/evidence/local-artifact-manifest.json
docs/evidence/local-provenance-report.json
```

These files are advisory only and do not replace protected CI artifacts.

The local manifest covers all served files under `apps/web/public`, including:

```text
apps/web/public/demo-control-room.js
apps/web/public/demo.html
apps/web/public/flow-data.json
apps/web/public/flow.js
apps/web/public/index.html
apps/web/public/live-demo-snapshot.json
apps/web/public/live-flow.js
apps/web/public/live.html
apps/web/public/partner-snapshot.json
apps/web/public/styles.css
```

The local inventory excludes generated Sprint 22 output files from its own hash inputs to avoid circular artifact hashing.

Local execution commands:

```powershell
pnpm --filter @giwa/web --fail-if-no-match artifact:local
pnpm --filter @giwa/web --fail-if-no-match artifact:manifest
pnpm --filter @giwa/web --fail-if-no-match artifact:provenance
pnpm --filter @giwa/web --fail-if-no-match artifact:scan
```

The scanner reports rule ids, paths, line numbers, classes, and decisions only. It does not print matched values.

## Sprint 23 Local Provenance Verification

Sprint 23 keeps the Sprint 22 artifact inventory intact and upgrades the local provenance report into a verifiable, nested local-advisory envelope.

Local output paths:

```text
docs/evidence/local-artifact-manifest.json
docs/evidence/local-command-evidence-report.json
docs/evidence/local-provenance-report.json
docs/evidence/local-provenance-report.json.sha256
docs/evidence/local-provenance-verification.json
```

Local execution commands:

```powershell
pnpm --filter @giwa/web --fail-if-no-match artifact:local
pnpm --filter @giwa/web --fail-if-no-match artifact:provenance:verify
pnpm --filter @giwa/web --fail-if-no-match artifact:provenance:verify -- --check
```

The Sprint 23 report binds to raw bytes of `docs/evidence/local-artifact-manifest.json`, not to a parsed-and-reserialized approximation. The report hash remains external-only through stdout and `docs/evidence/local-provenance-report.json.sha256`.

`docs/evidence/local-provenance-verification.json` records:

- manifest hash and byte binding decision
- timestamp-aware artifact drift decision
- sidecar match decision
- redacted public artifact scan binding
- local command evidence catalog binding
- domain hash classification from public evidence
- known source provenance and protected CI blockers

The local command evidence report is a command catalog and local-advisory binding. It does not create protected CI evidence, source commit evidence, release tags, promotion decisions, public hosting, deployment, wallet actions, or chain-operation evidence.
